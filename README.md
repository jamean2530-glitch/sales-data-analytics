# Sales Data Analytics & Quality Cleaning Dashboard

🌐 **Live Demo Website (GitHub Pages):**
👉 **[https://jamean2530-glitch.github.io/sales-data-analytics/](https://jamean2530-glitch.github.io/sales-data-analytics/)**

---

ระบบแดชบอร์ดสรุปและวิเคราะห์ข้อมูลยอดขาย 9,803 รายการ พร้อมรายงานการตรวจสอบคุณภาพและจุดผิดแปลก (Data Quality & Anomaly Report) พัฒนาด้วย Tailwind CSS และ Chart.js

### 📊 คุณสมบัติเด่นของระบบ
- **Executive KPI Cards:** สรุปยอดขายรวมสุทธิ ฿9,990,790, จำนวนสินค้าขายได้ 16,822 ชิ้น, และความสำเร็จคำสั่งซื้อ 92.5%
- **Interactive Visualizations:**
  - ยอดขายแยกตามหมวดหมู่สินค้า (Revenue by Category)
  - สัดส่วนยอดขายตามภูมิภาค (Revenue by Region)
  - แนวโน้มยอดขายรายเดือนตลอด 2 ปี (Monthly Trend 2024 - 2025)
  - สัดส่วนช่องทางการขาย (Sales Channel)
  - โครงสร้างลูกค้าตามกลุ่มอายุและเพศ (Demographics)
  - 10 อันดับสินค้าขายดีที่สุด (Top 10 Best Sellers)
- **Data Quality & Anomalies Report:** แจกแจงจุดผิดปกติ 6 ข้อที่ตรวจพบในไฟล์ต้นฉบับและการแก้ไข
- **Data Explorer Table:** ตารางค้นหาและกรองคำสั่งซื้อแบบเรียลไทม์
- **Download Cleaned Dataset:** ปุ่มดาวน์โหลดไฟล์ `sales_data_final_cleaned.csv`
